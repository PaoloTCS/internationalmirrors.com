IM-SWARM-001 Draft protocol

Common adversary, independent defense

Participants jointly design one bounded adversarial agent society. After a clean reset, each independently governed society must detect and contain it under matched conditions, with SARAI admitting only protocol-authorized information.

IM-INHERIT-001 Planned

Corrupted inheritance

Measure how a planted artifact is adopted, transformed, attributed, challenged, and either contained or normalized across agent generations.

IM-COMPOSE-001 Planned

Latent composition

Test when components judged acceptable in isolation produce an unacceptable capability after combination or contextual reuse.

IM-HANDOFF-001 Planned

Meaning across handoffs

Trace what is lost, distorted, completed, or discovered when an object passes through different agents and returns to its origin.

Disclosure discipline

Public questions do not imply public execution access.

Protocols, evaluation criteria, and bounded results can be public. Credentials, live control surfaces, raw private session material, proprietary mechanisms, and any path from a simulation to external authority remain protected.
