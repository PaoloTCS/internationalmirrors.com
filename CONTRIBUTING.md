# Contributing to International Mirrors

Thank you for your interest in contributing to International Mirrors! 🕵️‍♂️

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/internationalmirrors.com.git`
3. Create a branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Test locally: `npm run dev`
6. Format your code: `npm run format`
7. Commit your changes: `git commit -m "Add your message"`
8. Push to your fork: `git push origin feature/your-feature-name`
9. Create a Pull Request

## Code Style

- Run `npm run format` before committing
- Follow HTML5 best practices
- Keep the spy/humor theme consistent
- Ensure all links work properly

## Testing

Before submitting a PR:

- Test all pages locally with `npm run dev`
- Check responsive design on mobile/tablet/desktop
- Verify all forms work correctly
- Run linters: `npm run lint:html` and `npm run lint:css`

## Pull Request Guidelines

- Provide a clear description of changes
- Reference any related issues
- Include screenshots for UI changes
- Ensure all checks pass

## Questions?

Feel free to open an issue for discussion!
